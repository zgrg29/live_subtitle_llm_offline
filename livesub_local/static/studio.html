OBS 字幕の見た目を変える（AI 用プロンプト）

OBS のブラウザソースには「カスタム CSS」欄があります。下のプロンプトを AI に渡すと、 この字幕ページの構造を踏まえた CSS が返ってくるので、そのまま貼り付ければ見た目を変えられます。

  1. ソース → ブラウザ → プロパティを開き、「カスタム CSS」欄を探します。
  2. 下のプロンプトをコピーし、最後の 1 行を自分の希望に書き換えて AI に渡します。
  3. 返ってきた CSS を貼り付けて「OK」。変化がないときは !important の抜けを確認してください。
プロンプト（コピーして最終行を自分の希望に変える） 
あなたは LiveSub Local の OBS 字幕ページ用の CSS を書きます。

【使える構造】
#stage                     字幕ボックス（position:fixed 設定済み。変更しない）
#stage.bottom / .top / .center  表示位置（クラスで切り替わる）
.pair                      1 組の字幕（原文 + 訳文）
.pair .source              原文（display:none で隠れる場合あり）
.pair .target              訳文（1〜3 行）
#stage.idle                無音で薄くなっている状態

【使える変数】--target-size --source-size --outline --fade --gap

【必須条件】
1. すべてのセレクタは #stage で始める
2. #stage 自身のプロパティは !important 必須（ページはインラインスタイルを使う）
3. #stage:empty{...} のリセットを必ず入れる（無音時に空の枠が残るため）
4. @import、url()、@font-face、:has() は禁止
5. position / width / bottom は変更しない（位置は設定側で決まる）
6. 合計 4KB 以内。CSS だけを出力し、説明は書かない

【希望のデザイン】この行を自分の希望に置き換える

※ 非公式のカスタマイズです。ページ側の更新で CSS の調整が必要になる場合があります。 カスタム CSS 欄を空にすれば既定の見た目に戻ります。

デバッグ：音声なしで 1 文だけ送る（翻訳経路の確認）
