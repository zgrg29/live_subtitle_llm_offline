OBS 字幕の見た目を変える（AI 用プロンプト）

上のスタイルで足りないときは、このプロンプトを AI に渡して CSS を作り、OBS の「カスタム CSS」欄に貼ります。

  1. ソース → ブラウザ → プロパティ →「カスタム CSS」欄を開きます。
  2. プロンプトをコピーし、最終行を自分の希望に書き換えて AI に渡します。
  3. 返ってきた CSS を貼り付けて「OK」。変化がないときは !important の抜けを確認。
プロンプト（日本語） 
あなたは LiveSub Local の OBS 字幕ページ用の CSS を書きます。

【使える構造】
.sub-stage                  字幕ボックス（position:fixed 設定済み。変更しない）
.sub-stage[data-position]   表示位置（bottom / top）
.sub-pair                   1 組の字幕（原文 + 訳文）
.sub-source                 原文（非表示の場合あり）
.sub-target                 訳文（1〜3 行）

【使える変数】--target-size --source-size --target-color --source-color
             --outline --outline-color --gap --pair-bg --sub-font

【必須条件】
1. すべてのセレクタは .sub-stage で始める
2. .sub-stage 自身のプロパティは !important 必須（ページはインラインスタイルを使う）
3. .sub-stage:empty{...} のリセットを必ず入れる（無音時に空の枠が残るため）
4. @import、url()、@font-face、:has() は禁止
5. position / width / bottom は変更しない（位置は設定側で決まる）
6. 合計 4KB 以内。CSS だけを出力し、説明は書かない

【希望のデザイン】この行を自分の希望に置き換える

※ 非公式のカスタマイズです。ページ更新で調整が必要になる場合があります。

デバッグ：音声なしで 1 文だけ送る

「確定した文」として送られ、実際の翻訳キューを通ります。先に「字幕を開始」を押してください。
