# LiveSub Local v0.1.0

初回リリース。日本語の音声を、自分の PC だけで中国語字幕にして OBS に出すツールです。

- リリース日: 2026-11-02
- 配布物: `LiveSubLocal.exe`（16,456,972 バイト）
- SHA256: `E5EE5C143715AB52CFCF71F234412F6DFFF76DF22C142F440873EF8D172C9033`

## これは何か

マイクに向かって日本語で話すと、Chrome がブラウザ内で音声を認識し、このアプリが
確定した文だけを Qwen で中国語に翻訳して、OBS に貼れる字幕ページに表示します。

アカウント・決済・データベース・公開サーバーはありません。`127.0.0.1` だけで動きます。

> 「ローカル」は**サーバー不要**という意味です。完全オフラインではありません。
> 音声認識は Chrome のオンラインサービス、翻訳は Qwen API を使うため、ネット接続が必要です。

## 主な機能

- **認識はブラウザ内**：Chrome / Edge 内蔵の Web Speech API。音声は外部に送らず、認識した
  テキストだけを翻訳 API に送ります。
- **確定した文を 1 回だけ翻訳**：Qwen `qwen-mt-flash`。既定は 日本語 → 中国語。
- **25 言語から選択**：千問 MT が対応し、かつ Chrome が認識できる言語の共通部分。
- **リージョン切り替え**：中国本土（北京）/ 海外（シンガポール）。コンソールから切り替え、
  「接続テスト」でキーと通信を確認できます（配信中は切り替え不可）。
- **Apple 風のコンソール**：日本語 / 中文 / English の 3 言語、ライト・ダーク・自動。
- **字幕スタイル 14 項目**：フォント、原文 / 訳文のサイズと色、縁取り、背景色と不透明度、
  位置、表示する組数（2〜6、既定 2）、並び順、端からの距離、行間、自動で消えるまでの時間。
  変更は **OBS を再読み込みせずに** `/view` へ即時反映され、`settings.json` に保存されます。
- **マイクのレベルメーター**：ページを開くと自動で有効になります。入力ゲイン、発話しきい値
  （メーター上の目安表示）、マイクの選択。
- **OBS 用 URL のコピー**と、**カスタム CSS 用の AI プロンプト**（本物の DOM と CSS 変数を説明）。

## 動作環境

- Windows 10 / 11
- Chrome または Edge（Firefox / Safari は Web Speech API 非対応）
- Qwen の API キー（[アリババクラウド百錬](https://bailian.console.aliyun.com/) → API-KEY）

## 使い方

1. `LiveSubLocal.exe` を書き込み可能なフォルダ（例：`D:\LiveSub\`）に置きます。
2. ダブルクリックすると、同じフォルダに `config.toml` と `api.toml` が作られます。
3. `api.toml` をメモ帳で開き、`qwen.api_key` に自分のキーを入れて保存します。
4. もう一度 exe を起動すると、新しい Chrome ウィンドウでコンソールが開きます。
5. 「字幕を開始」を押し、マイクの使用を許可します。
6. OBS → ソース → **ブラウザ** → URL `http://127.0.0.1:8765/view`、幅 1920 / 高さ 1080、背景は透明。

## 設定ファイル

| ファイル | 内容 | git 管理 |
|---|---|---|
| `api.toml` | Qwen の API キー、リージョン、モデル | されない |
| `config.toml` | ポート、言語、字幕スタイルの初期値 | されない |
| `settings.json` | コンソールで変更したスタイルとリージョン | されない |

優先順位は `settings.json` → `config.toml` / `api.toml` → 既定値。
スタイルを初期値に戻すには `settings.json` を削除するか、コンソールの「既定に戻す」を押します。

## 既知の制限

- 同時に使えるコンソールは 1 つ（単機・単人想定）。
- 字幕の履歴保存・書き出し（SRT など）は未対応。
- 標準の字幕テーマは 1 種類。細かい見た目は OBS のカスタム CSS で。
- 認識のタイミング（VAD）は Chrome 側の内部処理です。コンソールの「発話しきい値」は
  メーター上の目安で、認識の開始・終了を変えるものではありません。
- 単一ファイル exe は起動時に `_MEIxxxx` を自身のフォルダへ展開します。書き込み可能な場所に置いてください。
